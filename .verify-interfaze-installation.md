# Interfaze Provider Verification Script

## How to Test Your Interfaze Provider Installation

Run this command in your Pi project directory to verify the Interfaze provider is properly loaded:

```bash
node scripts/verify-interfaze-provider.mjs
```

## What This Script Does

This verification script checks that your Interfaze provider is properly integrated by:

1. **Checking if the Interfaze provider is recognized** by the Pi framework
2. **Validating the interfaze-beta model** configuration
3. **Confirming API compatibility** settings are correct
4. **Verifying provider registration** with proper base URL

## Expected Output

When properly installed, you should see output similar to:

```
🔍 Verifying Interfaze AI Provider Installation...
✅ Interfaze provider detected in Pi framework
✅ interfaze-beta model loaded successfully
✅ Base URL configured correctly: https://api.interfaze.ai/v1
✅ Context window: 1000000 tokens
✅ Max output tokens: 32000
✅ Input modalities: text, image, audio, file, video
✅ Reasoning support: Available
✅ Provider ready for use!
```

## Prerequisites

- Pi framework properly installed
- Interfaze provider files in `extensions/lib/`
- API key set in environment variables (for actual usage)

## Troubleshooting

If the script reports issues:

1. **Check installation path**: Ensure files are in `extensions/lib/`
2. **Restart Pi**: Sometimes changes require Pi restart to take effect
3. **Verify API key**:
   ```bash
   export INTERFAZE_API_KEY="your-api-key-here"
   ```
4. **Check permissions**: Ensure all files have correct read permissions

This verification confirms your Interfaze AI integration is working correctly within the Pi framework.
